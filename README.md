# 🏫 نظام إدارة المتربصين الذكي (School System)

نظام ويب متكامل ومطور خصيصاً لإدارة المتربصين، رصد الغيابات، وتوليد بطاقات الهوية الذكية المعتمدة على رموز الاستجابة السريعة (QR Code). تم تصميم وتطوير هذا المشروع كجزء من التدريب التطبيقي في تخصص **الميكرو معلوماتية** بمركز التكوين المهني والتمهين **علوش الهاشمي - برج بوعريريج**.

---

## ✨ المميزات الرئيسية للنظام:
* **لوحة تحكم إحصائية (Dashboard):** تعرض نظرة عامة على أعداد الأقسام، المتربصين، وعمال الإدارة والرقابة.
* **إدارة الأقسام (Sections Management):** تنظيم المتربصين حسب التخصصات والمستويات الحاضرة في المركز.
* **منظومة رصد الغياب (Attendance System):** تسجيل غيابات وحضور المتربصين بشكل يومي وسلس.
* **الهويات الذكية (QR Codes):** واجهة مخصصة لتوليد وإدارة الرموز الذكية للمتربصين لتسهيل الرقابة.
* **إدارة الحسابات:** صلاحيات دخول مخصصة للمستخدمين والمشرفين لحماية البيانات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack):
* **اللغة الأساسية:** Python 
* **إطار العمل:** Flask (Python Web Framework)
* **الواجهات الأمامية:** HTML5 / CSS3 (مع تصميم متجاوب يشتغل على الهواتف والكمبيوتر)
* **خادم الإطلاق الحي:** Render & Gunicorn

---

## 📅 خطة التطوير القادمة:
1. ربط المنظومة بقاعدة بيانات ثابتة ودائمة (SQLite).
2. تفعيل كاميرا الهاتف/الكمبيوتر لقراءة الـ QR Code وتسجيل الحضور آلياً.
3. إدراج البيانات والإحصائيات الرسمية والشاملة لمركز علوش الهاشمي فور استلامها من الإدارة.
